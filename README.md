LinguaAI

AI-powered language analysis web app built using Azure AI Language Service.
LinguaAI analyzes text and provides intelligent language insights such as sentiment detection, key phrase extraction, and language understanding in a simple web interface.

🚀 Features
🌍 Language Analysis using Azure AI
😊 Sentiment Detection
🔑 Key Phrase Extraction
⚡ Fast and Simple UI
☁️ Azure Cognitive Services Integration
💻 Built with Node.js and Express
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Cloud AI: Azure AI Language Service

⚙️ Installation

Clone the repository:

git clone https://github.com/gauravaryan8840388332-maker/linguaAI.git

Go to the project folder:

cd linguaAI

Install dependencies:

npm install
🔐 Azure Setup
Create an Azure Language Service resource in
Microsoft Azure
Get:
API Key
Endpoint URL
Create a .env file:
AZURE_LANGUAGE_KEY=your_api_key
AZURE_LANGUAGE_ENDPOINT=your_endpoint
▶️ Run the Project
npm start

Server will start on:

http://localhost:3000
